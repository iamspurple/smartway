# Календарь Smartway — статический шаблон для WordPress

Вся разметка находится в `index.html`: 24 месяца (январь 2026 — декабрь 2027), карточка события, таблица, фильтры, баннер и FAQ. Страница работает без сборки. Хедер не включен.

В `script.js` оставлены только:

- плавное перелистывание готовых карточек и обновление названия просматриваемого месяца;
- отключение стрелок на границах: вправо нельзя листать, когда декабрь 2027 уже полностью виден;
- переключение календаря и таблицы;
- синхронизация видимого текста селекта месяца с его выбранным пунктом.

JS не создает HTML, не фильтрует события, не меняет выбранную дату, месяц или H1, не формирует URL. При листании активная карточка и дата остаются такими, как заданы в HTML. При адаптации слайдер учитывает количество полностью видимых карточек.

## Интеграция с WordPress

- H1, активные состояния (`is-selected`, `aria-current`) и данные событий формируются в шаблоне WordPress.
- Месяцы, даты с событиями и кнопки материалов используют `href="#"`; заменить на реальные ссылки.
- Выбор года и фильтры — готовая разметка без прикладной логики. Пункты фильтров соответствуют ТЗ.
- Таблица содержит шесть демонстрационных строк из макета. Заменить циклом по данным WordPress, с группировкой по месяцам.
- FAQ раскрывается стандартным HTML `details`; тексты ответов пока демонстрационные.
- Локальные ресурсы находятся в `images/` и `fonts/`. Golos Text распространяется по SIL OFL; при распространении добавить файл лицензии из https://github.com/google/fonts/blob/main/ofl/golostext/OFL.txt.

Открыть `index.html` напрямую либо запустить из `smartway`: `python3 -m http.server 8080`, адрес — `http://localhost:8080/calendar/`.
